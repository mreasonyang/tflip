# Tflip implementation contract

Current identity: Tflip / @kyun.si/tflip@0.3.2. Runtime selectors, browser preferences, events, Skill and public distributions use Tflip names. `src/types.ts` is the shared API contract.

- TypeScript ESM, .js extensions in source imports, strict mode. Browser runtime dependency-free except optional React peer. Root exports core + dom; effects and react are separate subpaths. Source tooling: Node ^22.22.2 || ^24.15.0 || >=26.0.0; published SDK metadata retains Node >=20.
- core/index.ts exports normalizeOptions(options: TrajectoryOptions): NormalizedTrajectory, sample(timeMs:number, options:TrajectoryOptions|NormalizedTrajectory): Pose, stateAt alias, presets and all core types. Pure math, no DOM reads at module scope; validate non-finite/invalid input; deterministic arbitrary seek; exact endpoints; continuous phase boundaries. CSS coordinate convention x right/y down, angles degrees. Relative height lifts y negative. Intermediate path points absolute pixels. Ratios normalized positive sum, must handle zero-length phases safely.
- dom/index.ts exports play(options):Playback, createAnimator(defaults):Animator, sequence(steps:readonly MotionOptions[]):Sequence, wrap(element):{element:HTMLElement,dispose():void}. wrap is explicit vanilla-only and restores original DOM; React supplies dedicated wrapper. play never reparents live business content. In-place requires dedicated wrapper; transforms restored on finish/cancel. Transfer requires fresh detached visual factory; fixed overlay, decorative/inert, never clones arbitrary content. from/to Elements resolve centers. Default from is element center; default to same center. Default mode inferred from visual. Registry keyed by element or from Element; replacement cancels old, ignore returns existing controller, queue returns queued controller. Queue starts after active settles. Support callbacks and on subscriptions. No rAF/listeners/observer/effect after settle/cancel. rAF active only; time uses actual elapsed delta, pause freezes, hidden tabs suspend by visibilitychange. Browser globals accessed only on calls, clear SSR error for play.
- finished always resolves finished/cancelled; setup validation errors throw synchronously; runtime/effect errors cancel with error. replay returns NEW controller + promise. seek clamps; no land/finish solely from seek; subsequent resume finishes normally. land once when crossing descent→settle, before finish. callbacks safe against reentrancy. initial start is deferred to microtask so play returns before callbacks fire. reducedMotion instant completion via microtask, no movement/effects. System preference changes to reduce should settle immediately. Cancellation restores caller styles; cleanup happens before settling promise. Default layout=cancel on scroll/resize, freeze uses measured coordinates, follow resamples anchors; source disconnect cancels. Default repeat=replace, autoplay=true.
- effects/index.ts exports createParticles(options?:{jet?:boolean;trail?:boolean;density?:number;color?:string;seed?:number}):EffectFactory; optional canvas pointer-events none. Stateless/reproducible render by time and seed, no independent rAF. Own cleanup, resize/DPR cap; reduced motion draws nothing. DOM calls factory in full-viewport overlay context; Pose x/y are viewport centers.
- react/index.tsx exports Motion (forwardRef dedicated div wrapper, preserves child transform), useMotion(ref, defaultOptions?) returning play(overrides?), cancel, playback ref or state as documented. Avoid state updates after unmount; cancel all pending/queued runs; StrictMode and SSR safe. Examples explain explicit transfer visual ownership.
- sequences run steps in order, control current step, expose aggregate progress/time, cancellation prevents next step, replay returns new Sequence. Basic seek across steps must be documented/tested, or implement a clear supported contract rather than pretending support.
- Packaging uses npm build tsc; tests node:test (compiled dist). Browser interaction uses Brave or the built-in Browser. Static hosting is Cloudflare Pages at tflip.kyun.si. npm publishing uses the exact canonical SDK archive through `npm run publish:npm`, with public access. The source workspace remains private; consumer SDK metadata is publishable and contains no lifecycle scripts. Registry availability requires a completed npm publication; catalog `published: false` means it has not been confirmed.
- Full scope includes advanced path waypoints + smooth/linear mode, sequence API, axis/turns/direction, height/depth/bounce, duration/phase ratios/speed, pause/resume/cancel/replay/seek, jet/trail/shadow/backface, lifecycle events/repeat/reduced motion. Playground must show these and config copy; editable waypoints can use JSON editor rather than unvalidated drag editor.

Release policy: MIT license; public source at https://github.com/mreasonyang/tflip. Website, local delivery and npm publication use the same canonical SDK. Static output must be complete, remove retired assets, and return HTTP 404 for missing paths. Source revision and artifact hashes are recorded in the release manifest. Registry publication and availability must be verified separately from local packaging. Physical-device acceptance is separate from emulation.

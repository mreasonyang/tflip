# Tflip 双镜头演示

自 0.3.0 起延续既有两套独立镜头：完整 8 秒 U/C 型跑道动作后，在 8,000ms 直接切换到完整 5.8 秒汽车飞越动作，总长 13,800ms。各自保留构图、相机、几何与本地时间；共用播放、暂停、停止、速度和进度控制。

正式接入 ID 为 `stunt`。Roadster / Ramp 场景别名均选择整段 Stunt，不单独隔离某一镜头。七个场景示例加上 Lab 共 8 个 Demo。

车辆场景为非官方的程序化视觉演绎，不代表真实物理仿真或实拍。此次命名清理未改变镜头与轨迹算法。新版本验收以 [当前验证记录](VERIFICATION.md) 为准。
